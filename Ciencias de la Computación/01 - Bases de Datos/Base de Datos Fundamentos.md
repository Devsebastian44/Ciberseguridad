## ¿Qué es una Base de Datos?

Una **base de datos** es un conjunto organizado de información o datos estructurados, típicamente almacenados electrónicamente en un sistema informático.

Permiten el almacenamiento, modificación y acceso eficiente a los datos.

**Ejemplos:** sistemas bancarios, plataformas de streaming, redes sociales

**Tipos:**

- Relacionales (SQL)
- No relacionales (NoSQL)

---

## ¿Qué es SQL?

**SQL (Structured Query Language)** es un lenguaje estándar para el manejo de bases de datos relacionales.

**Permite:**

- Crear estructuras (tablas, vistas)
- Insertar, consultar, actualizar y eliminar datos (CRUD)
- Controlar acceso a los datos

---

## ¿Qué es NoSQL?

**NoSQL (Not Only SQL)** es un conjunto de tecnologías de bases de datos no relacionales diseñadas para trabajar con datos de forma flexible y escalable.

**Características principales:**

- Almacenar datos en modelos flexibles (documentos, clave-valor, columnas, grafos)
- Escalar horizontalmente añadiendo más servidores
- Procesar grandes volúmenes de datos en tiempo real
- Trabajar con datos estructurados, semiestructurados o no estructurados
