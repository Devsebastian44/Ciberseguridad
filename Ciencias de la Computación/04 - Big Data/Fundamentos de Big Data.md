## Introducción

**Big Data** se refiere a conjuntos de datos extremadamente grandes y complejos que no pueden ser gestionados con herramientas **tradicionales**.

---

## Características de Big Data

**Las 5 V's:**

- **Volumen:** cantidad masiva de datos generados
- **Velocidad:** rapidez con la que se generan y procesan los datos
- **Variedad:** diferentes tipos de datos (estructurados, no estructurados, semiestructurados)
- **Veracidad:** fiabilidad y calidad de los datos
- **Valor:** utilidad de los datos para tomar decisiones

---

## Impacto de Big Data

**Beneficios principales:**

- Mejora la **toma de decisiones** basadas en datos
- **Optimiza** procesos empresariales
- Potencia la **personalización** de productos y servicios
- Identifica **patrones** y tendencias
- Impulsa **innovaciones** tecnológicas y científicas

## Big Data y Ciencia de Datos

### Plataforma de Big Data

**Componentes principales:**

- **Recolección** y almacenamiento masivo
- **Procesamiento** distribuido (batch/tiempo real)
- **Análisis** avanzado (ML, minería de datos)
- **Visualización** y toma de decisiones

**Ejemplos:** Hadoop, Spark, NoSQL, ETL

---

### Ciencia de Datos

**Relación:**

- Big Data proporciona los **datos**
- Ciencia de Datos extrae **conocimiento** útil

---

**Habilidades requeridas:**

- **Bases de datos:** SQL, NoSQL

---

## Procesamiento de Big Data

### Ecosistema de Herramientas

**Componentes principales:**

- **Almacenamiento:** HDFS, S3, GCS
- **Procesamiento:** Hadoop, Spark, Flink
- **Bases de datos:** Cassandra, MongoDB, HBase
- **Ingesta:** Kafka, NiFi, Flume
- **Visualización:** Jupyter, Tableau, Kibana

---

### Hadoop

**Componentes del ecosistema:**

- **HDFS:** sistema de archivos distribuido
- **MapReduce:** procesamiento paralelo
- **YARN:** gestión de recursos
- **HBase:** NoSQL distribuido
- **Hive:** consultas tipo SQL
- **Pig:** lenguaje de alto nivel
- **Zookeeper:** coordinación distribuida

---

**Ventajas de Hadoop:**

- **Escalabilidad** horizontal
- Alta **tolerancia** a fallos
- Bajo **coste** con hardware común
