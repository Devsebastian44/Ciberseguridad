## Actividades Realizadas con IA
Con la asistencia de **ChatGPT**, logramos:

1. **Exploración inicial de datos**  
   - Analizamos brevemente las bases de ventas y el perfil del cliente de **Zoop**.  
   - Identificamos variables clave: ventas, clientes, productos, fechas.  

2. **Integración y organización de datos**  
   - Unimos las bases en una tabla consolidada.  
   - Preparamos la estructura para futuros análisis y visualizaciones.  

3. **Investigación de posibles visuales**  
   - ChatGPT sugirió gráficos para la narrativa del informe:  
     - Barras comparativas de ventas por producto.  
     - Series temporales de ventas mensuales.  
     - Segmentación de clientes por perfil/demografía.  
     - Mapas de calor para correlaciones entre variables.  

---

## Buenas Prácticas de *Prompt Engineering*

- **Claridad**: Explicar el contexto del negocio y los datos disponibles.  
- **Especificidad**: Indicar qué tipo de visual o análisis se busca.  
- **Iteración**: Refinar el *prompt* con base en las respuestas de la IA.  
- **Ejemplo de Prompt Usado**:  

```
Tengo una base de datos de ventas y clientes de Zoop. ¿Qué tipos de gráficos me recomiendas para mostrar tendencias de ventas y segmentación de clientes en un informe ejecutivo?
```
