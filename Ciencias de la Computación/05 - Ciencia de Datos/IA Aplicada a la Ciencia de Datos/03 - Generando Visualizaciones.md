## Actividades con ChatGPT

Con la asistencia de ChatGPT logramos:

- **Generar códigos para visuales de proporción y distribución**  
  - Ejemplo: pie chart de ventas por categoría.  
  - Histograma de distribución de clientes por edad.  

- **Crear visuales sin especificar el tipo de gráfico**  
  - A partir de instrucciones sobre los datos existentes.  
  - Ejemplo: “mostrar ventas por región” → ChatGPT propone barras o mapas.  

- **Variar el tipo de gráfico con los mismos datos**  
  - Con la misma tabla de ventas, generamos:  
    - Gráfico de barras.  
    - Gráfico de líneas.  
    - Gráfico de pastel.  

---

## Ejemplo de Prompt Usado

```
Tengo una tabla con las columnas 'categoría' y 'ventas'. Genera un gráfico de proporción que muestre la participación de cada categoría en las ventas totales usando Matplotlib.
```

### Ejemplo de Prompt Optimizado

```
Usa Matplotlib para crear un gráfico de pastel con la columna 'categoría' y la columna 'ventas'. Agrega porcentajes en cada sección y un título en español.
```
