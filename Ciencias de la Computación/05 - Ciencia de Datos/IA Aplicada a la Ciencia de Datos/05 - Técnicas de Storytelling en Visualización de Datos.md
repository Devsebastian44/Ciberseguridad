## Actividades con ChatGPT

Con la asistencia de ChatGPT conseguimos:

- **Personalizar elementos visuales de un gráfico**  
  - Título, ejes, rótulos y paleta de colores.  

- **Destacar información con colores y textos informativos**  
  - Ejemplo: resaltar la categoría con mayor participación en un gráfico de barras.  

- **Añadir puntos de interés al gráfico**  
  - Señalar valores específicos para comparaciones.  
  - Uso de anotaciones y etiquetas adicionales.  

- **Refinar gráficos ya desarrollados**  
  - Ajustes en el código generado por ChatGPT para mejorar estética y narrativa.  

---

## Ejemplo de Prompt Usado

```
Genera un gráfico de barras con Matplotlib que muestre las ventas por producto. Usa una paleta de colores contrastante para destacar el producto con mayores ventas. Agrega título y etiquetas en español.
```

### Ejemplo de Prompt Optimizado

```
Usa Matplotlib para crear un gráfico de barras con la columna 'producto' y 'ventas'. Destaca el producto con mayores ventas en color rojo, los demás en azul. Agrega un título descriptivo, etiquetas en español y una anotación sobre el valor máximo.
```
