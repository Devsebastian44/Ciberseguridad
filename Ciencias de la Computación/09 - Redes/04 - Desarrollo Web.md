## Depuración con DevTools

Los **DevTools** de los navegadores permiten inspeccionar y depurar aplicaciones web.  
Funciones principales:
- Analizar el código HTML y CSS.  
- Revisar solicitudes y respuestas HTTP.  
- Medir rendimiento y tiempos de carga.  
- Depurar errores en JavaScript.

## Clientes HTTP

Herramientas como **Postman** y **cURL** permiten probar y analizar APIs:  
- **Postman:** Interfaz gráfica para construir y enviar solicitudes HTTP.  
- **cURL:** Herramienta de línea de comandos para realizar solicitudes y verificar respuestas.  
Ambas son esenciales para validar la comunicación entre cliente y servidor.

## Separación front-end y back-end

Las aplicaciones web modernas se dividen en dos partes:  
- **Front-end:** Interfaz visual con la que interactúa el usuario (HTML, CSS, JavaScript, frameworks como React o Angular).  
- **Back-end:** Lógica del servidor, gestión de datos y APIs (lenguajes como Python, Node.js, Java, bases de datos).  
Esta separación permite escalabilidad y mantenimiento más eficiente.

## APIs en desarrollo web

Las **APIs (Application Programming Interfaces)** permiten la comunicación entre aplicaciones.  
Tipos principales:
- **REST:** Basado en HTTP, utiliza métodos como GET, POST, PUT y DELETE.  
- **GraphQL:** Permite consultas más flexibles y específicas, optimizando la transferencia de datos.  

Las APIs son el puente entre front-end y back-end.

## Hospedaje en la nube

Hospedar aplicaciones en la nube facilita el acceso global y la escalabilidad.  
Servicios principales:
- **AWS (Amazon Web Services)**  
- **Microsoft Azure**  
- **Google Cloud Platform (GCP)**  

Estos servicios ofrecen infraestructura, almacenamiento y herramientas para desplegar aplicaciones modernas.

## Roles en el desarrollo web moderno

- **Front-end developer:** Diseña y construye la interfaz de usuario.  
- **Back-end developer:** Implementa la lógica del servidor y gestiona bases de datos.  
- **DevOps:** Automatiza procesos de despliegue, integración continua y monitoreo.  
- **QA engineer:** Garantiza la calidad de la aplicación mediante pruebas y validaciones.  
- **Security engineer:** Protege la información y previene vulnerabilidades en aplicaciones web.

## Importancia de QA y seguridad

- El **QA engineer** asegura que las aplicaciones funcionen correctamente y cumplan estándares de calidad.  
- El **ingeniero de seguridad** protege contra ataques, asegura la confidencialidad de los datos y mantiene la confianza de los usuarios.
