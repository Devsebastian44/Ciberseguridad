## JSON (JavaScript Object Notation)

**JSON (JavaScript Object Notation)** es un **formato ligero** para almacenar e intercambiar datos. Es muy utilizado para **comunicarse entre el frontend y el backend**, y se basa en la **sintaxis de objetos de JavaScript**.

### Ejemplo de JSON

```javascript
{
  "nombre": "Sebastián",
  "edad": 25,
  "activo": true
}
````

Un objeto JSON está compuesto por:

- **Claves (keys)** en strings
- **Valores** que pueden ser: `string`, `number`, `boolean`, `array`, `object`, o `null`

---

## Crear un Objeto JavaScript

```javascript
let persona = {
  nombre: "Sebastián",
  edad: 25,
  activo: true
};
```

---

## Convertir de Objeto JS a JSON String

### **`JSON.stringify()`**

Convierte un objeto JavaScript en una cadena JSON.

```javascript
let jsonString = JSON.stringify(persona);
console.log(jsonString);
// Resultado: {"nombre":"Sebastián","edad":25,"activo":true}
```

---

## Convertir de JSON String a Objeto JS

### **`JSON.parse()`**

Convierte una cadena JSON en un objeto JavaScript.

```javascript
let texto = '{"nombre":"Sebastián","edad":25,"activo":true}';
let objeto = JSON.parse(texto);
console.log(objeto.nombre); // Resultado: Sebastián
```

---

## JSON con Arrays

### Formato JSON

```javascript
{
  "usuarios": [
    { "nombre": "Ana", "edad": 30 },
    { "nombre": "Luis", "edad": 25 }
  ]
}
```

### En JavaScript

```javascript
let datos = {
  usuarios: [
    { nombre: "Ana", edad: 30 },
    { nombre: "Luis", edad: 25 }
  ]
};

console.log(datos.usuarios[1].nombre); // Luis
```
