## ¿Qué es `fetch()`?

El método **`fetch()`** se utiliza para hacer **peticiones HTTP** (GET, POST, PUT, DELETE, etc.) de manera sencilla en JavaScript. Devuelve una **Promise** que se resuelve con la respuesta de la petición.

---

## Sintaxis Básica

```javascript
fetch(url, opciones)
  .then(response => {
    // Manejar la respuesta
  })
  .catch(error => {
    // Manejar errores
  });
````

- **`url`** → la dirección a la que se hace la petición
- **`opciones`** → objeto opcional para configurar el método, cabeceras, body, etc.

---

## Ejemplo GET (Obtener Datos)

```javascript
fetch("https://jsonplaceholder.typicode.com/posts/1")
  .then(response => response.json()) // Convertimos la respuesta a JSON
  .then(data => {
    console.log(data); // Mostramos el objeto recibido
  })
  
  .catch(error => {
    console.error("Error en la petición:", error);
  });
```

**Salida esperada en consola:**

```json
{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere repellat provident occaecati",
  "body": "quia et suscipit..."
}
```

---

## Ejemplo POST (Enviar Datos)

```javascript
fetch("https://jsonplaceholder.typicode.com/posts", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  
  body: JSON.stringify({
    title: "Nuevo post",
    body: "Contenido del post",
    userId: 1
  })
})

  .then(response => response.json())
  .then(data => {
    console.log("Post creado:", data);
  })
  
  .catch(error => {
    console.error("Error en la petición:", error);
  });
```

Se envía un objeto y el servidor responde con el **recurso creado**.

---

## Ejemplo con **`async / await`**

```javascript
async function obtenerDatos() {
  try {
    let response = await fetch("https://jsonplaceholder.typicode.com/users");
    let usuarios = await response.json();
    console.log(usuarios);
  } catch (error) {
    console.error("Error al obtener usuarios:", error);
  }
}

obtenerDatos();
```

## Ejemplo Mostrando en HTML

```html
<div id="contenido"></div>

<script>
  fetch("https://jsonplaceholder.typicode.com/users/1")
    .then(res => res.json())
    .then(user => {
      document.getElementById("contenido").innerHTML =
        `<p><b>Nombre:</b> ${user.name}</p>
         <p><b>Email:</b> ${user.email}</p>`;
    });
</script>
```
