## ¿Qué es una Promesa?

Una **promesa** es un objeto en JavaScript que representa el **resultado eventual de una operación asíncrona**. Puede estar en uno de tres estados:

1. **Pendiente (pending)** → la operación aún no terminó
2. **Cumplida (fulfilled)** → la operación terminó con éxito
3. **Rechazada (rejected)** → la operación falló

---

## Sintaxis Básica

```javascript
let promesa = new Promise((resolve, reject) => {
  // Operación asíncrona
  let exito = true;

  if (exito) {
    resolve("La operación fue exitosa ✅");
  } else {
    reject("Hubo un error ❌");
  }
});

promesa
  .then(resultado => {
    console.log(resultado); // Si se cumplió
  })
  .catch(error => {
    console.error(error); // Si fue rechazada
  });
````

---

## Ejemplo Simple con `setTimeout`

```javascript
let tarea = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("Tarea completada después de 2 segundos ⏳");
  }, 2000);
});

tarea.then(mensaje => {
  console.log(mensaje);
});
```

**Salida en consola (después de 2 segundos):**

```
Tarea completada después de 2 segundos ⏳
```

## Encadenar Promesas (Then Chaining)

```javascript
let promesa = new Promise(resolve => {
  resolve(10);
});

promesa
  .then(numero => {
    console.log("Número inicial:", numero);
    return numero * 2;
  })
  .then(resultado => {
    console.log("Resultado multiplicado:", resultado);
    return resultado + 5;
  })
  .then(final => {
    console.log("Resultado final:", final);
  });
```

**Salida:**

```
Número inicial: 10
Resultado multiplicado: 20
Resultado final: 25
```

## Promesas con **`catch`**

```javascript
let promesa = new Promise((resolve, reject) => {
  reject("Algo salió mal ❌");
});

promesa
  .then(resultado => {
    console.log(resultado);
  })
  .catch(error => {
    console.error(error);
  });
```

**Salida:**

```
Algo salió mal ❌
```

---

## Promesas con **`finally`**

```javascript
let promesa = new Promise((resolve, reject) => {
  resolve("Proceso exitoso ✅");
});

promesa
  .then(msg => console.log(msg))
  .catch(err => console.error(err))
  .finally(() => console.log("Promesa finalizada (éxito o error)."));
```

**Salida:**

```
Proceso exitoso ✅
Promesa finalizada (éxito o error).
```

## Ejecutar Varias Promesas a la Vez

### Con **`Promise.all`** (todas deben cumplirse)

```javascript
let p1 = Promise.resolve("Primera promesa");
let p2 = Promise.resolve("Segunda promesa");

Promise.all([p1, p2]).then(resultados => {
  console.log(resultados); // ["Primera promesa", "Segunda promesa"]
});
```

### Con **`Promise.race`** (la primera en cumplirse gana)

```javascript
let p1 = new Promise(resolve => setTimeout(() => resolve("Primera"), 1000));
let p2 = new Promise(resolve => setTimeout(() => resolve("Segunda"), 500));

Promise.race([p1, p2]).then(resultado => {
  console.log(resultado); // "Segunda"
});
```
