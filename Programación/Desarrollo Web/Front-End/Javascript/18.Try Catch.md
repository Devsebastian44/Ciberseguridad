## ¿Qué es `try...catch`?

El bloque **`try...catch`** se utiliza para **manejar errores** en JavaScript y evitar que el programa se detenga cuando ocurre una **excepción**.

---

## Sintaxis Básica

```javascript
try {
  // Código que puede causar un error
} catch (error) {
  // Código que maneja el error
}
````

---

## Ejemplo Básico

```javascript
try {
  let x = y + 5; // ❌ Error: y no está definida
} catch (error) {
  console.log("Ocurrió un error:", error.message);
}
```

**Salida en consola:**

```
Ocurrió un error: y is not defined
```

---

## Ejemplo con **`finally`**

El bloque **`finally`** se ejecuta **siempre**, haya o no error.

```javascript
try {
  console.log("Intentando ejecutar código...");
  let resultado = 10 / 2;
  console.log("Resultado:", resultado);
} catch (error) {
  console.log("Error detectado:", error.message);
} finally {
  console.log("Finalizó el bloque try...catch");
}
```

**Salida:**

```
Intentando ejecutar código...
Resultado: 5
Finalizó el bloque try...catch
```

---

## Lanzar Errores con **`throw`**

Puedes lanzar tus propios errores con **`throw`**.

```javascript
function dividir(a, b) {
  if (b === 0) {
    throw new Error("No se puede dividir entre 0 ❌");
  }
  return a / b;
}

try {
  console.log(dividir(10, 0));
} catch (error) {
  console.error("Error atrapado:", error.message);
}
```

**Salida:**

```
Error atrapado: No se puede dividir entre 0 ❌
```

## Ejemplo con JSON y Error de Parseo

```javascript
let texto = "{ nombre: 'Juan' }"; // ❌ JSON inválido

try {
  let datos = JSON.parse(texto);
  console.log(datos.nombre);
} catch (error) {
  console.error("Error al parsear JSON:", error.message);
}
```

**Salida:**

```
Error al parsear JSON: Unexpected token n in JSON at position 2
```
