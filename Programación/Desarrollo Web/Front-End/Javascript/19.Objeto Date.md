## ¿Qué es el Objeto `Date`?

El objeto **`Date`** en JavaScript se utiliza para **trabajar con fechas y horas**. Permite crear, obtener y modificar fechas.

---

## Crear un Objeto Date

### Fecha Actual

```javascript
let fechaActual = new Date();
console.log(fechaActual);
````

Muestra la **fecha y hora actual**.

---

## Crear Fechas Específicas

```javascript
let fecha1 = new Date("2025-09-15");
let fecha2 = new Date(2025, 8, 15); // Año, Mes (0=Enero), Día
let fecha3 = new Date(2025, 8, 15, 10, 30, 0); // Año, Mes, Día, Hora, Min, Seg

console.log(fecha1);
console.log(fecha2);
console.log(fecha3);
```

---

## Métodos para Obtener Información

```javascript
let fecha = new Date();

console.log("Año:", fecha.getFullYear());     // 2025
console.log("Mes:", fecha.getMonth());        // 0-11 (0 = enero)
console.log("Día del mes:", fecha.getDate()); // 1-31
console.log("Día de la semana:", fecha.getDay()); // 0=domingo, 6=sábado
console.log("Horas:", fecha.getHours());      // 0-23
console.log("Minutos:", fecha.getMinutes());  // 0-59
console.log("Segundos:", fecha.getSeconds()); // 0-59
console.log("Milisegundos:", fecha.getMilliseconds()); // 0-999
console.log("Timestamp:", fecha.getTime());   // ms desde 1970
```

---

## Métodos para Establecer Valores

```javascript
let fecha = new Date();

fecha.setFullYear(2030);
fecha.setMonth(5);   // Junio
fecha.setDate(10);
fecha.setHours(14);
fecha.setMinutes(45);

console.log(fecha);
```

---

## Formatos de Fecha

```javascript
let fecha = new Date();

console.log("Formato local:", fecha.toLocaleDateString()); // 15/9/2025
console.log("Formato ISO:", fecha.toISOString());          // 2025-09-15T14:30:00.000Z
console.log("Formato string:", fecha.toString());          // Mon Sep 15 2025 ...
```

---

## Comparar Fechas

```javascript
let hoy = new Date();
let navidad = new Date("2025-12-25");

if (hoy < navidad) {
  console.log("Aún falta para Navidad 🎄");
} else {
  console.log("Ya pasó Navidad 🎅");
}
```

---

## Calcular Diferencia Entre Fechas

```javascript
// Creamos la fecha de inicio
let inicio = new Date("2025-01-01"); // Objeto Date → 1 de enero de 2025

// Creamos la fecha de fin
let fin = new Date("2025-09-15"); // Objeto Date → 15 de septiembre de 2025

// Restamos las fechas → resultado en milisegundos
let diferenciaMs = fin - inicio; // Ej: 22291200000 ms

// Convertimos milisegundos a días
let dias = diferenciaMs / (1000 * 60 * 60 * 24); 
// 1000 ms = 1s, 60s = 1min, 60min = 1h, 24h = 1 día

// Mostramos el resultado en consola
console.log("Días entre fechas:", dias); // 257
```
