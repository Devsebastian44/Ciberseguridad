## Crear el archivo Python

1. Clic derecho sobre el proyecto
2. **New → Python File**
3. Nombre: `hola_mundo`

---

## Escribir el código del programa

### Archivo y ruta

```
ProyectoInicial/hola_mundo_proyecto/01-04-00-HolaMundo-UP.py
```

### Código

```python
# Programa de Hola Mundo con Python
print("Hola mundo con Python")
print('Saludos')
```

### Explicación

- `#` → comentario, no se ejecuta
- `print()` → muestra texto en consola
- Comillas simples o dobles son válidas

---

## Ejecutar el programa

1. Clic derecho sobre `hola_mundo.py`
2. Seleccionar **Run 'hola_mundo'**

### Resultado esperado

```
Hola mundo con Python
Saludos
Process finished with exit code 0
```

---

## Conceptos clave aprendidos

|Concepto|Descripción|
|---|---|
|`print()`|Imprime mensajes en consola|
|`#`|Comentarios|
|`'` y `"`|Comillas válidas para cadenas|
|`.py`|Extensión de archivos Python|
